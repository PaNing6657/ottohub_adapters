# 2026-08-20 工作日志

## OTTOhub 社交能力插件(astrbot_plugin_ottohub_actions)

项目根目录的独立 AstrBot 插件,让机器人获得 OTTOhub 社交操作能力,支持**命令 + LLM 工具**双模式:

- 命令(12 个):`/用户详情` `/发动态` `/动态详情` `/搜索动态` `/评论` `/回复` `/关注` `/取关` `/关注状态` `/发消息` `/会话列表` `/ottohub帮助`
- LLM 工具(8 个):ottohub_get_user_detail / post_blog / get_blog_detail / search_blogs / comment_blog / follow_user / unfollow_user / send_message
- 文件:main.py、ottohub_client.py(自包含,401 自动重登录)、_conf_schema.json、metadata.yaml、README.md、logo.png

### 行为约定(用户需求)
- 发动态末尾自动署名:`\n\n—— 由「{发送者昵称}」让我代发`;正文超长截断正文保留署名
- 评论/回复开头自动加:`{发送者昵称}让我转达:`;总长超 459 字截断正文保留前缀
- 昵称:`event.get_sender_name()`,回退 sender.nickname / user_id
- 写操作(发动态/评论/关注/发消息)受「管理员用户ID」白名单约束
- 已移除"获得经验值奖励"提示
- LLM 工具用 `return str` 把结果(成功/失败/审核状态)交回 LLM 组织语言,不用 plain_result 直接发;命令方式仍 plain_result 直接回复

### 踩坑记录
- `_conf_schema.json` 嵌套分组(connection/permission)时,AstrBot 存配置为 `config["connection"]["token"]`,`_cfg()` 须先查顶层再遍历分组,否则读不到配置("未配置 OTTOhub 账号")
- async 函数内 yield 与 return 值不能混用;llm_tool 要么全程 yield plain_result(直接发),要么全程 return 字符串(给 LLM),二选一

### 关键 API 确认(AstrBot 官方文档)
- `filter.command(name, alias=set)`;`filter.llm_tool(name=...)` 从 docstring `Args:` 段解析 schema(格式 `参数名(类型): 描述`),不读类型注解
- 工具调用需模型支持 function calling,并在 WebUI 工具管理中启用

### 踩坑:EventMessageType 导入兼容
- 报错 `cannot import name 'EventMessageType' from 'astrbot.api.event'`:部分版本该枚举在 `astrbot.api.event.filter` 子模块,不在顶层导出
- 兼容写法(社区通用,omnidraw 同款):`try: from astrbot.api.event import EventMessageType; except ImportError: from astrbot.api.event.filter import EventMessageType`

### 踩坑:事件过滤器装饰器命名
- 报错 `module 'astrbot.api.event.filter' has no attribute 'event_type'`:目标版本装饰器名为 `event_message_type`(官方内置 `builtin_stars/astrbot/main.py` 用 `@filter.event_message_type(filter.EventMessageType.ALL, priority=...)`)
- 兼容写法:`_event_type_filter = filter.event_message_type if hasattr(filter, 'event_message_type') else filter.event_type`,装饰时用 `@_event_type_filter(...)`;拦截用 `event.stop_event()`
